# Лабораторная работа № 3. Вариант № 2

**Тема:** Создание простых классов. Геттеры и сеттеры.

**Задание 2 (средний уровень):** создать класс `Date2` с полями «день», «месяц», «год», конструкторами, деструктором, геттерами, сеттерами и методами увеличения года на 1 и уменьшения даты на 2 дня. Продемонстрировать работу с готовой и введённой пользователем датой.

**Дополнительные задания для повышенной оценки:**
1. Статический счётчик созданных объектов.
2. Перегрузка оператора `<<`.
3. Массив объектов `Date2`.
4. Сохранение объекта в текстовый файл и загрузка из него.

**Реализация:** `main.cpp`. Программа проверяет правильность дат, учитывает високосные годы и смену месяца/года. При добавлении года дата 29.02 становится 28.02, если следующий год не високосный.

**Запуск:** создать проект Console App (C++) в Visual Studio, добавить `main.cpp` и запустить `Ctrl + F5`. Ввести три числа: день, месяц и год (например, `10 5 2024`). Программа создаёт файл `date2.txt` автоматически.
